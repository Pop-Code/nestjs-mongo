    save

    • save<Model extends EntityInterface>(
          entity: Model | WithId<Model>,
          options?: SaveOptions,
      ): Promise<WithId<Model>>

      Saves an entity, after its validation and its @BeforeInsert() / @BeforeUpdate() hooks.

      • without _id, the entity is inserted;
      • with an _id, every property is written with $set (the undefined properties are removed with $unset), and the document is inserted when it does not exist.

      For a model with a @Version() property, the update fails with an OptimisticLockException when the version of the document is not the version of the entity. To change some properties only, use patch.
